| Boundary | Description |
|----------|-------------|
| Internet → `*.pages.dev` (Pages) | le pack original (ressources PopCap) est servi uniquement derrière Cloudflare Access ; seul `/public/` est en Bypass |
| session cloud → API Cloudflare | le jeton (droits d'écriture sur Pages et Access du compte) est injecté par le proxy ; le JWT d'envoi transite dans les en-têtes |

| service worker ↔ flux de connexion Access | le SW ne doit ni intercepter `/cdn-cgi/` ni servir une réponse inadaptée à une navigation |
