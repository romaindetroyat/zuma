**Formes de l'API (relues dans `cloudflare-typescript` et `workers-sdk`, branche principale, 2026-10-11 ; aucun appel au compte) :**
- KV : `GET /accounts/:a/storage/kv/namespaces?per_page&page` ; `POST …/namespaces { title }` (400 si le titre existe) ; `GET …/namespaces/:ns/keys?limit≤1000&prefix&cursor` (`result_info.cursor`) ; `PUT …/namespaces/:ns/bulk` = tableau `{ key, value, base64 }`, ≤ 10 000 paires et ≤ 100 Mo par requête, valeur ≤ 25 Mio, clé ≤ 512 octets, réponse `{ successful_key_count, unsuccessful_keys }`.
- Projet : `PATCH /accounts/:a/pages/projects/:p { deployment_configs: { production|preview: { kv_namespaces: { NOM: { namespace_id } }, compatibility_date } } }` (null retire une liaison) ; `GET` renvoie `canonical_deployment.deployment_trigger.metadata.commit_message` et `latest_stage`.
- Déploiement : `POST …/deployments` multipart : `manifest` (JSON), `branch`, `commit_message`, `commit_dirty`, et `_worker.js` (fichier ; exclusif de `_worker.bundle`).
- **Écart au brief, imposé par la plateforme :** `ASSETS` est la liaison réservée de Pages (le `Fetcher` des fichiers statiques, `env.ASSETS.fetch`) ; une liaison KV de ce nom serait refusée ou masquée. La liaison KV s'appelle donc `ZUMA_FILES`.
