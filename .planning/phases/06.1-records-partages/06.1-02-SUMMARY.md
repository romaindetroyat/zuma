# Phase 6.1 Plan 02: API des records partagés du worker Summary

GET / POST `/api/records` added to the generated Pages worker on a separate D1 database `zuma-scores` (binding `SCORES_DB`): the 10 best scores of all players and of the requester, the best time per level with its author's first name and the personal times. The first name is set by the server from the Access JWT e-mail (`PLAYERS`, else « Joueur »), and the identity stored is SHA-256 of the lower-cased e-mail. Writes are D-10-bounded, same-origin, JSON, at most 4 096 bytes and rate-limited per identity, using a closed list of prepared statements that is verified on a real SQLite database.
